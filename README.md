# MediBizAnalytics 자료 저장소

치과 **결산 표준(5기준)** 교육 시리즈의 공개 자료입니다.
수록된 모든 데이터는 **가상 예시**입니다 — 실제 치과 자료·상호가 아닙니다.

## 치과 결산 5기준 표준 (제안)

하나의 **기간별 진료비**를 보는 렌즈에 따라 5가지 결산 기준으로 나눕니다. 모든 명칭을 **4자·계층구조로 통일**했습니다.

| 기준 | 총계 | = | 좌 | + | 우 |
|---|---|---|---|---|---|
| 진료기준 | 총진료비 | = | 보험진료 | + | 일반진료 |
| 수납기준 | 총수납액 | = | 카드수납 | + | 현금수납 |
| 수입기준 | 총수입액 | = | 공단청구 | + | 환자수납 |
| 과세기준 | 총매출액 | = | 과세매출 | + | 면세매출 |
| 현영기준 | 총현금액 | = | 현영발행 | + | 현영미발 |

> **제안하는 표준입니다.** 공인·법정 회계·세무 기준이 아닙니다. 덴트웹 기간별 진료비를 바탕으로 설계했으며, 원클릭 등 다른 전자차트 자료도 대동소이합니다.

## 자료

- **`01_기간별진료비/`**
  - `덴트웹_기간별진료비통계_연월.xlsx` — 덴트웹 기간별 진료비(가상) 월별 집계. 원본테이블(내려받은 형식 그대로 — 전부 문자) + 편집테이블(합계·평균) + 결산 5기준 시트.
